OBJECTIF PRODUIT
----------------
CovoiTour est une application de covoiturage regulier entre les memes personnes pour un meme trajet.

Slogan principal :
"Le covoiturage equitable ou chacun conduit a son tour."

Slogan court pour l'interface :
"A qui le volant aujourd'hui ?"

- suivi clair des participants ;
- interface moderne Material 3.

REGLES METIER A RESPECTER
-------------------------
1. Un trajet CovoiTour represente une journee aller-retour. L'aller et le retour sont comptabilises ensemble.
2. Il n'y a pas de calcul de score pour un demi-trajet.
3. Pour N passagers transportes :
   - conducteur : +N points ;
   - chaque passager : -1 point ;
   - absent : 0 point ;
   - somme totale : toujours 0.
4. L'application propose un conducteur, mais le groupe peut confirmer un autre membre.
5. Tous les membres actifs peuvent conduire si leur vehicule et leur capacite le permettent.
6. En cas d'egalite, choisir la personne qui a conduit le moins recemment.
7. Les scores sont separes selon le nombre de participants du trajet.
8. Un membre qui rejoint commence avec 0 et ne modifie pas l'historique passe.
9. Un membre qui quitte est archive, mais son historique et ses scores restent conserves.
10. L'administrateur peut corriger les scores, modifier une journee ancienne ou annuler une journee.
11. Toute modification doit conserver une somme de scores egale a 0 et etre tracee dans l'historique.
12. Les membres doivent declarer present, absent ou non repondu avant le trajet.
13. Un rappel de declaration doit etre prevu deux jours avant le trajet.

INSTALLATION DE L'ENVIRONNEMENT
--------------------------------
Installer sur le poste de developpement :

1. Flutter stable, qui contient Dart.
2. Android Studio version recente.
3. Android SDK.
4. Android SDK Platform Tools, incluant adb.
5. Un JDK compatible avec la version du projet Android genere par Flutter.
6. Git.

Dans Android Studio :
- installer les plugins Flutter et Dart ;
- verifier le chemin du Flutter SDK ;
- verifier le SDK Android ;
- connecter un telephone Android ou creer un emulateur ;
- activer le debogage USB sur le telephone si necessaire.

VERIFICATIONS OBLIGATOIRES AVANT DE CODER
-----------------------------------------
Depuis PowerShell, a la racine du projet :

  flutter --version
  dart --version
  flutter doctor -v
  git status --short

Si le dossier android/ n'existe pas encore, executer une seule fois :

  flutter create --org com.covoitour --project-name covoi_tour --platforms=android .

Le package Android attendu est :

  com.covoitour.covoi_tour

Ensuite executer :

  flutter pub get
  flutter analyze
  flutter test

Puis lancer sur un appareil :

  flutter devices
  flutter run

IMPORTANT : ne pas lancer `flutter create` si le dossier Android a deja ete genere, sauf apres avoir verifie les consequences. Ne pas ecraser les fichiers applicatifs existants.

COMPILATION RELEASE
-------------------
Pour generer un APK installable :

  CompilationRelease.bat

APK attendu :

  build\app\outputs\flutter-apk\app-release.apk

Pour installer l'APK sur un telephone autorise :

  TransfertRelease.bat

Pour une installation propre :

  TransfertRelease.bat --clean

Pour la publication Play Store, generer plutot un AAB :

  flutter build appbundle --release

Ne jamais commiter :
- android/local.properties ;
- fichiers .jks, .keystore ou .p12 ;
- secrets OAuth ;
- dossiers build/ et .dart_tool/ ;
- tokens ou cles privees.
